# oldschool-pack-fix
Attempts to frame Team Fortress 2 and its art-style in the era of GoldSrc engine games

This repository uses [git-lfs](https://git-lfs.com/) so make sure to have it installed so you can clone/commit/pull/push without any issues!

If you are trying to compile this from source, please check out the [compiler](https://github.com/Voids29/oldschool-pack-compiler) made for this repository!
